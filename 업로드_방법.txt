하교 후 미션 - GitHub Pages 업로드 안내

1. 이 ZIP 파일의 압축을 해제합니다.
2. GitHub에서 새로운 Public 저장소를 만듭니다 (예: afterschool-mission).
3. 압축 해제한 index.html 파일을 저장소 최상위에 업로드하고 Commit changes를 누릅니다.
4. 저장소 Settings > Pages > Build and deployment에서 Source: Deploy from a branch,
   Branch: main, Folder: /(root)를 선택하고 Save를 누릅니다.
5. Pages 화면에 표시되는 웹 주소를 아이폰 또는 아이패드 Safari에서 엽니다.
6. Safari 공유 버튼 > 홈 화면에 추가를 누르면 앱 아이콘처럼 사용할 수 있습니다.

주의
- 아이별 데이터는 각 기기의 브라우저에 따로 저장됩니다.
- 소리 기능은 사용자가 화면을 터치해 시작해야 할 수 있습니다.
- 화면 잠금/백그라운드 상태에서는 알람 소리 재생을 보장할 수 없습니다.
- 저장소가 Public이면 프로그램 소스는 누구나 볼 수 있습니다. 아이의 이름 등 개인정보를 HTML 파일에 직접 적어 올리지 마세요.
